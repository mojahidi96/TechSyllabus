# TechSyllabus

A collection of study notes and curated learning resources for software engineering topics.

## Topics

- **Angular** — interview and design questions on change detection, application architecture, signals and RxJS, performance, and micro-frontends.
- **DSA** — algorithm and data structure notes, including an LRU Cache, plus curated topic lists and learning links.
- **Node.js** — notes on the event loop, scaling, API architecture, and API security.
- **Tech Skills** — broader technical skills and learning topics.
